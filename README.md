Solarium Resort — Sistema de Reservas

Aplicação web desenvolvida com React, TypeScript e Tailwind CSS para simular a experiência de um hóspede buscando e reservando acomodações de luxo em um resort de alto padrão.

O Projeto

O Solarium Resort permite navegar por quartos exclusivos, configurar datas de estadia, gerenciar hóspedes e simular o fluxo completo de uma reserva através de um carrinho de compras.

Principais Funcionalidades

* Home: Apresentação visual do resort com carrossel de imagens.
* Catálogo de Quartos: Listagem detalhada das acomodações disponíveis.
* Carrinho de Reservas: Gerenciamento e acompanhamento dos quartos selecionados.
* Customização de Hóspedes: Seleção dinâmica de adultos e crianças por quarto.
* Cálculo de Estadia: Atualização em tempo real baseada nas datas escolhidas.
* Design Responsivo: Layout totalmente adaptado para mobile, tablet e desktop.

Como Executar?

Certifique-se de ter o **Node.js** instalado na sua máquina.

1. Clone o repositório:

```bash
git clone https://github.com/Amanda-Correa2003/solarium-resort.git

```

2. Entre na pasta do projeto:

```bash
cd solarium-resort

```

3. Instale as dependências:

```bash
npm install

```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev

```

5. Acesse no navegador o link fornecido no terminal (geralmente `http://localhost:5173`).
